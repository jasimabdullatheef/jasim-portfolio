## Preview
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a new GitHub repository (for example, `jasim-portfolio`).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your public website URL.

## Before publishing
- Replace the generic GitHub project links with the direct repository URLs for each project.
- Add your LinkedIn URL and professional email/contact method.
- Four certificate PDFs are included in the `certificates/` folder and linked from the Certificates section.
- Add project screenshots/dashboard images and concise measured outcomes where available.

This is a static, responsive website. Project filters and mobile navigation work in the browser; no server is required.
